# Contributing

Use Bun and the committed lockfile. Run **bun run check** before submitting
a change. Include an observable behavior change and relevant validation.

Keep script wording intact, use neutral synthetic examples, and never commit
API keys, recordings, private drafts or user preferences.
Changes to voice tracking need examples for partial revisions, repeated
phrases, fillers, silence and manual seeking.

Test UI changes in the local iframe preview. Test host-specific changes in
the actual host and state the host/version and any limitations.
Update the UI resource URI when its cached contract changes.

Contributions are licensed under MIT, as the project is.
